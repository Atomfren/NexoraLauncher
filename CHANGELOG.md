# Changelog

## [1.7.0] — 2026-10-28 «Шире круг»

### 🧩 Отдельные моды из CurseForge
- Поиск и установка одиночных модов из каталога CurseForge — там лежит половина модов, которых нет на Modrinth. Раньше оттуда ставились только сборки.
- Нужен бесплатный ключ API: без него каталог объясняет, где его взять, а не отдаёт пустоту. Моды, запрещённые к стороннему скачиванию, не роняют установку — лаунчер даёт ссылку на страницу.
- Моды из CurseForge проверяются на обновления наравне с Modrinth, источник виден у каждого.

### 🖥️ Свой сервер — по-взрослому
- Белый список и права оператора прямо из лаунчера: на запущенном сервере командой, на остановленном — правкой файлов. Для лицензии UUID берётся у Mojang, в офлайне считается из ника, и об этом сказано прямо.
- Бэкапы мира по расписанию, пока сервер работает: раз в N часов, с паузой записи перед копией и ограничением на число хранимых копий.
- Консоль с подсветкой: ошибки и предупреждения отделены, виден вход и выход игроков, есть поле команды и фильтр «только проблемы».

### 🩺 Доктор учится на согласии
- Лаунчер может отправить **отпечаток вылета** — не лог, а короткую подпись ошибки, — чтобы разборы становились точнее. Отправка только по согласию, каждый раз, с показом того, что уйдёт; по умолчанию не уходит ничего.
- После исправления — вопрос «помогло?». Ответ уходит вместе с отпечатком.
- Из подписи вычищены ники, почта, имя пользователя Windows, пути, ссылки, токены и хэши. IP не отправляется и на сервере не хранится. Подробно — на странице «Безопасность» сайта.

### 🚀 Мелочи
- Тест держит время запуска: сборка падает, если слой интерфейса начнёт тянуть за собой backend.

## [1.6.1] — 2026-10-28

### ✉️ Понятный отказ при вводе почты
- Окно проверяло адрес мягче, чем сервер: адрес уходил на сервер и возвращался отказом «нужен настоящий адрес почты», хотя никакой ящик никто не проверял. Теперь обе проверки совпадают, и окно отвечает сразу.
- Подсказка называет причину: адрес нужен латиницей, без двух точек подряд. Чаще всего отказ вызывала одна случайная русская буква в адресе — на вид её не отличить.

## [1.6.0] — 2026-10-28 «Скин с собой»

### 👤 Аккаунт Nexora: скин и плащ хранятся на сервере
- В окне «Добавить аккаунт» появилась вкладка **Nexora**: вход по нику или почте и регистрация там же. Пароль никуда не сохраняется — лаунчер хранит только токен сессии, и тот зашифрованным.
- Скин и плащ такого аккаунта лежат на сервере (nexoralauncher.ru), а не рядом с лаунчером: они те же самые на другом компьютере и подтягиваются в 3D-модель персонажа сразу после входа.
- С модом [CustomSkinLoader](https://github.com/xfl03/MCCustomSkinLoader) скин виден и в самой игре, в том числе в офлайне. Источник в настройках мода: `https://nexoralauncher.ru/api/csl/`.
- «Сбросить скин» у аккаунта Nexora удаляет текстуры и на сервере — иначе при следующем запуске они приехали бы снова.
- Сессия живёт 30 дней и продлевается молча, когда до конца остаётся меньше недели. Удаление аккаунта закрывает сессию и на сервере.
- Лицензию Minecraft аккаунт Nexora не заменяет: для игры это по-прежнему офлайн-вход.

### 🔑 Подготовка входа через Microsoft
- Приложение Azure теперь одно на весь лаунчер: идентификатор вписывается в сборку, и игроку не нужно заводить своё. Пока он не получен, вкладка Microsoft честно говорит, что вход недоступен, и не показывает кнопку, которая не сработает.
- Как зарегистрировать приложение и получить доступ к Minecraft API — в `docs/microsoft-login.md`.

### 🧹 Мелочи
- В «Настройках → О программе» кнопка «Исходный код» вела на GitHub. Код закрыт, поэтому теперь там ссылка на сайт лаунчера.

## [1.5.1] — 2026-10-23 «Своими силами»

### 🎮 Игра запускается на дискретной видеокарте
- На ноутбуках Windows по умолчанию отдавала игру встроенной графике — отсюда низкий FPS там, где его быть не должно. Теперь лаунчер сам выбирает дискретную видеокарту.
- Настройки → «Игра и память» → **Видеокарта для игры**: авто (дискретная, если она есть), дискретная, встроенная или «как в Windows». Рядом написано, какая видеокарта нашлась.

### ⬆️ Обновления приходят сами и проверяются подписью
- Лаунчер проверяет обновления при запуске и ещё раз, когда появляется интернет: если при старте сети не было, новая версия не потеряется. Раньше в новом интерфейсе автопроверки не было вовсе.
- Обновления берутся с **nexoralauncher.ru**, а не с GitHub. Манифест выпуска подписан, у архива сверяется SHA-256: подменённое обновление лаунчер не поставит.

### 🌍 Языки можно докачать с сайта
- Настройки → **Языки**: список переводов с сайта, установка в один клик, удаление там же. Видно, насколько перевод полон и кто его сделал.
- Непереведённые строки показываются по-английски, так что неполный перевод не ломает интерфейс.
- Переводы подписаны тем же ключом, что и обновления.

### 🛠️ Внутри
- Интерфейс переведён с PyQt6 на PySide6 (LGPL): лицензия Qt больше ничего не навязывает проекту. Попутно исправлено исчезновение окна при сборке мусора.
- Свой установщик на Rust вместо Inno Setup: тихая установка, запись в «Приложения», деинсталлятор; CI проверяет полный цикл установки и удаления на чистой машине.
- Ошибка в проверке введённых значений больше не роняет backend.

## [1.5.0] — 2026-10-20 «Всё на своих местах»

### 🏷️ Любые названия сборок
- В названии сборки теперь можно использовать «:» и другие символы, запрещённые в именах папок: например, «Create: Above & Beyond». Папка получает безопасное имя, а в интерфейсе название остаётся таким, как вы его ввели.
- Модпаки с Modrinth и сборки из Prism, MultiMC и CurseForge сохраняют своё исходное название.
- Переименование: если новое название подходит для папки, переименовывается и папка. Иначе меняется только отображаемое название.

### 🖥️ Свой сервер: настройки и моды в новом интерфейсе
- **Сеть → свой сервер → «Настройки»:** описание (MOTD), число игроков, режим игры, сложность, хардкор, PvP, полёт, Нижний мир, командные блоки, online-mode, белый список, дальность прорисовки и симуляции, защита спавна, сид мира. Сохраняется сразу; если сервер запущен, лаунчер напомнит его перезапустить.
- **«Моды» (Fabric) и «Плагины» (Paper, Purpur):** список установленного с размером и версией, удаление в один клик и кнопка «Найти в каталоге», которая сразу выбирает этот сервер целью установки. Мод e4mc помечен: он нужен для адреса друзьям.
- Исправлено: два быстрых изменения настроек подряд могли затереть друг друга.

### 🌍 Экспорт и импорт мира
- На вкладке «Миры» появились кнопка экспорта мира в .zip (чтобы отправить другу или перенести в другую сборку) и кнопка «Импорт мира». Мир с таким же именем не перезаписывается, а получает имя «Мир (2)».

### ⚡ Список версий Minecraft без ожидания
- Список версий Mojang сохраняется на диск: при следующем запуске он открывается мгновенно, а без интернета показывается последний сохранённый.

### 🛠️ Исправления по отзывам
- **Полный экран** у сборки снова работает: игра брала режим из своего options.txt (его меняет F11) и игнорировала настройку лаунчера. Теперь перед запуском лаунчер записывает туда свою настройку.
- **Удаление сборки** больше не обрывается на «Нет доступа». Если файлы держит игра или другая программа, лаунчер называет её, а сборка остаётся целой. Атрибут «только чтение» снимается, короткие блокировки антивируса переживаются повтором, а остатки прерванного удаления (например, пустая папка без настроек) дочищаются при следующем запуске.
- **«Турбо»** больше не срабатывает через раз: при сбое сети каждый мод скачивается повторно (до 3 попыток). Если мод так и не скачался, лаунчер прямо об этом говорит, а не пишет «готово».
- **Сворачивание при запуске игры** теперь работает и в новом интерфейсе: окно сворачивается, когда игра запустилась, и возвращается, когда она закрыта. Для новых установок включено по умолчанию (Настройки → Общие).

### 🖼️ Своё фото на фон
- Меню сборки (⋮) → «Своё фото на фон…» или «Настройки сборки → Фон»: выберите любую картинку с компьютера. Она будет фоном сборки и её обложкой в списке. Кнопка «Убрать» возвращает последний скриншот.

### 📦 Сборки FTB и All The Mods
- **Каталог → Модпаки** и мастер «Новая сборка»: выбор источника **Modrinth · FTB · CurseForge**.
  - **FTB**: StoneBlock, Skies, Evolution и другие сборки Feed The Beast.
  - **CurseForge**: All The Mods (ATM10, ATM10 To the Sky, ATM11, ATM9 и др.); пустой поиск показывает All The Mods.
- Сборка ставится целиком: нужная версия Minecraft и NeoForge/Forge/Fabric, все моды (по 8 загрузок параллельно, с проверкой SHA-1 и повторами), конфиги, квесты и скрипты. Рекомендованная авторами память выставляется сама. При ошибке недоустановленная сборка удаляется.
- Списки и описания сборок берутся из открытого API FTB и сохраняются на диск: каталог открывается сразу и показывает последнюю копию без интернета.
- Запасной путь: если API FTB недоступен, сборки CurseForge ставятся через официальный API CurseForge — ключ с console.curseforge.com указывается в «Настройки → Общие» (хранится зашифрованным). Моды, которые авторы запретили скачивать автоматически, лаунчер не обходит, а перечисляет.

### 🧍 Ваш персонаж в шапке сборки
- Справа в шапке — 3D-модель персонажа активного аккаунта со скином и плащом. Её можно крутить мышью, она слегка «дышит». Под моделью ник: стрелки ‹ › переключают аккаунты, «+» добавляет новый. Кнопка аккаунта из боковой панели убрана.
- Откуда берётся скин: свой файл, если выбран; у Microsoft-аккаунта — скин из профиля; у офлайн-ника — скин и плащ лицензионного игрока с таким же ником (с Mojang, кэш на сутки); иначе Стив или Алекс из установленной версии игры.
- Клик по нику: свой скин (обычные или тонкие руки), свой плащ, сброс, все аккаунты. Свой скин виден в лаунчере; в офлайн-игре без мода скинов его не будет.

### 🧭 Боковая панель где удобно
- «Настройки → Общие → Боковая панель»: слева, справа, сверху или снизу. Сверху и снизу панель становится полосой с подписями разделов.
- Логотип Nexora в углу панели — ссылка на сайт.

### 📥 Собственный установщик
- Установщик теперь свой, на Rust: окно в стиле лаунчера, выбор папки, ярлык на рабочем столе, запуск после установки. Права администратора не нужны.
- Обновление на месте: файлы новой версии подменяют старую папку целиком, лишние файлы от прошлых версий не остаются, при ошибке старая версия возвращается. Версия от прежнего установщика (Inno Setup) удаляется автоматически, сборки и миры остаются.
- Деинсталлятор в «Параметры → Приложения»; по желанию стирает и данные. Тихий режим: `--silent`, `--dir`, `--no-desktop`, `--launch`, `--remove-data`.
- CI на чистой машине ставит лаунчер собранным установщиком, запускает самопроверку и удаляет его.

### 🧪 Тесты
- Новые тесты: названия с недопустимыми символами, кэш списка версий, настройки и моды своего сервера, экспорт и импорт мира. Устранена нестабильность теста боковой панели под нагрузкой.

## [1.4.0] — 2026-10-13 «OptiFine и умные логи»

### 🎨 Новый интерфейс на Qt Quick (QML)
- Интерфейс сделан заново по макету «библиотека, а не админка»: 4 раздела — **Библиотека**, **Каталог**, **Сеть**, **Настройки**. Прежний интерфейс доступен флагом `--ui classic`.
- **Библиотека:** список сборок с обложками, справа выбранная сборка на фоне последнего скриншота. Одна кнопка «Играть» с состояниями: установить → прогресс → играть → остановить с таймером. Рядом меню: зайти на сервер, играть с друзьями, проверить файлы.
- Вкладки сборки: Обзор (недавние миры, скриншоты, вердикт Доктора, свой сервер), Моды (выбор, включение, обновления, «Турбо», OptiFine), Ресурсы, Миры, Снимки, Диагностика (умные логи), Настройки (память, Java, окно, точки восстановления).
- **Мастер «Новая сборка»** на всю страницу: чистая игра, с модами, модпак из каталога, перенос из Prism/MultiMC/CurseForge.
- **Каталог:** моды, модпаки, ресурспаки, шейдеры, плагины; фильтры по версии, загрузчику и категории; строка «Ставлю в: <сборка>»; карточка проекта с версиями и галереей; прогресс установки прямо в строке.
- **Сеть:** избранные серверы с цветным MOTD и пингом, свой сервер с адресом для друзей, консолью и бэкапами.
- Уведомления в углу вместо модальных окон, значок «Загрузки» со списком задач, Ctrl+K — поиск сборок и действий, перетаскивание .jar/.zip/.mrpack на окно, тёмная («глубинный сланец») и светлая («песчаник») темы, иконки Lucide.

### 🔆 OptiFine
- Пункт «OptiFine» в меню инстанса. Список версий берётся с официального сайта optifine.net, для каждой указаны нужная версия Forge и дата выхода.
- Автор OptiFine запрещает распространять файлы в обход своего сайта, поэтому лаунчер открывает страницу загрузки выбранной версии, **сам находит скачанный файл в папке «Загрузки»** и ставит его в один клик. Можно и выбрать файл вручную.
- **Vanilla + OptiFine:** установка без окон, как у официального установщика: `optifine.Patcher` и launchwrapper, отдельный профиль `<версия>-OptiFine_<редакция>`. Проверено вживую на Minecraft 26.1.2 (OptiFine HD U K1 pre2): игра загрузилась до главного меню.
- **Forge + OptiFine:** OptiFine ставится как мод, старая версия заменяется. Если файл пропал из mods, лаунчер вернёт его при следующем запуске.
- Для Fabric, Quilt и NeoForge OptiFine не работает, поэтому лаунчер предлагает замену в один клик: Sodium + Iris.
- При смене версии игры или загрузчика OptiFine снимается автоматически. Карточка инстанса показывает «+ OptiFine».

### 🧠 Умные логи
- Новая вкладка «Логи»: все запуски, `latest.log` игры и отчёты о сбоях в одном списке. Текущий запуск обновляется в реальном времени.
- **Сводка сеанса:** версия игры и загрузчика, число модов, Java, видеобиблиотека, время загрузки, исход (вылетела / закрыта нормально / запущена), причина вылета, моды, с которыми связаны ошибки.
- **Проблемы с кнопками исправления** (правила Доктора): установить недостающий мод, отключить конфликтующий, выделить память и т. д.
- Пояснения простым языком к частым ошибкам: нехватка памяти, Mixin, не та Java, видеодрайвер, сеть, повреждённый мод, повреждённый мир, шейдеры и др.
- **Шум скрывается:** безвредные предупреждения (звуки, шрифты, Realms, ключи профиля при офлайн-аккаунте) не мешают искать настоящие ошибки.
- Определение мода-виновника по Mixin, тегу логгера и пакетам в стек-трейсе.
- Повторы схлопываются (×N), стек-трейсы сворачиваются, есть фильтр по уровню, поиск с подсветкой и кнопка «К первой ошибке».
- «Поделиться»: лог публикуется на mclo.gs, ссылка копируется. Токены, IP-адреса и имя пользователя Windows перед отправкой удаляются.
- Поддерживаются форматы Vanilla, Fabric, Quilt, Forge, NeoForge и отчёты о сбоях. Проверено на реальных логах.

## [1.3.0] — 2026-10-12 «Свой мир»

### 🌍 Свой сервер: любое ядро и бэкапы
- **Выбор ядра сервера:** Fabric (моды и публичный адрес через e4mc), **Paper** и **Purpur** (плагины), **Vanilla**. Ядра скачиваются с официальных источников: Fabric Meta, PaperMC Fill API, Purpur API, Mojang.
- **Плагины для Paper и Purpur.** Поиск на Modrinth (Paper/Spigot/Bukkit) с учётом версии сервера, установка с зависимостями, удаление. Fabric-моды на Paper поставить нельзя, и наоборот.
- **Резервные копии мира.** Копия делается автоматически после каждой остановки сервера (хранятся последние N), а также вручную в любой момент, даже на работающем сервере: лаунчер временно выключает автосохранение (`save-off` / `save-all flush`). Восстановление в один клик, текущий мир перед этим тоже сохраняется. Ручные копии не удаляются автоматически.
- В настройках сервера: «Резервная копия после каждой остановки» и число хранимых автокопий.
- Для ядер без туннеля карточка честно показывает, что адрес работает только в локальной сети.

### ⬆ Автообновление лаунчера

## [1.1.0] — 2026-10-11 «Nexora Smart»

Лаунчер теперь сам находит и исправляет проблемы сборки.

### 🩺 Доктор Nexora
- Разбирает последний лог запуска и crash-report: не хватает мода-зависимости, мод не для этой версии игры или загрузчика, несовместимые моды, нехватка памяти, не та Java, сбой Mixin, повреждённые jar, проблемы видеодрайвера, моды из «Suspected Mods».

- У каждой проблемы есть кнопки исправления: установить недостающий мод с Modrinth (mod id сопоставляется со slug автоматически), отключить или удалить мод, выделить память, вернуть Java от Mojang, обновить загрузчик.
- При вылете игры лаунчер сразу предлагает «Диагностировать».

### 🕓 Машина времени
- Снимки модов, конфигов, options.txt и настроек инстанса. Откат в один клик, при этом статистика игры сохраняется.
- Автоснимки делаются перед обновлением модов, «Турбо», исправлениями Доктора, сменой версии или загрузчика и перед самим откатом. Хранятся последние 10.

### ⬆ Умные обновления
- Моды распознаются по SHA-1 через Modrinth, включая добавленные вручную: у них появляются названия и иконки.
- Обновления проверяются под версию игры и загрузчик инстанса. Можно обновить всё разом или выбрать отдельные моды. Отключённые моды остаются отключёнными.

### 🚀 Турбо
- Один клик ставит набор проверенных оптимизаций под загрузчик: Sodium/Embeddium, Lithium, FerriteCore, Entity Culling, ImmediatelyFast, ModernFix, Krypton. Уже установленные и конфликтующие (например, второй движок рендера) пропускаются.
- Подбирает память по числу модов и объёму RAM, включает настройки G1 GC.

### 📤 Поделиться сборкой

## [1.0.0] — 2026-10-11

Первый стабильный релиз. Backend и frontend переписаны; закрыты все критические и высокоприоритетные пункты из `AUDIT_REPORT.md`.

### Запуск игры
- Исправлен запуск, который всегда падал с ошибкой `'function' object has no attribute 'get'`: callback установки теперь передаётся в формате minecraft-launcher-lib.
- У каждого инстанса своя игровая папка (`gameDirectory`). Версии, библиотеки, ассеты и Java общие для всех.
- Поддержка загрузчиков Fabric, Quilt, Forge и NeoForge (minecraft-launcher-lib 8). Версию загрузчика можно выбрать.
- Java от Mojang скачивается автоматически под каждую версию игры. Можно указать свою Java для всего лаунчера или для отдельного инстанса.
- Настройки памяти, аргументов JVM и разрешения можно переопределять на уровне инстанса.
- Загрузка повторяется при сетевых сбоях, ошибки сети показываются понятным сообщением.
- Процессы игры отслеживаются: лог в реальном времени и в файле, сообщение при вылете, статистика времени в игре. Один и тот же инстанс нельзя запустить дважды.
- Вывод игры переведён в UTF-8, кириллица в логах больше не искажается.
- Подключение к серверу использует выбранный инстанс, а не несуществующую версию `latest`.

### Контент
- Единый каталог Modrinth для модов, модпаков, ресурспаков и шейдеров с фильтрацией по версии и загрузчику инстанса.
- Обязательные зависимости модов устанавливаются автоматически. Проверяются хэши SHA-512/SHA-1. Обновление мода заменяет старый файл.
- Контент можно включать и выключать, удалять, добавлять из локального файла.
- Импорт `.mrpack` скачивает все файлы модпака и ставит загрузчик (раньше распаковывались только overrides).
- Миры: импорт и экспорт в `.zip`, удаление.

### Аккаунты
- Вход Microsoft работает полностью: device code → Xbox Live → XSTS → Minecraft. Токен обновляется автоматически, ошибки Xbox объясняются понятным текстом.
- Можно держать несколько аккаунтов и переключать активный.
- UUID офлайн-аккаунтов совпадает с алгоритмом ванильного сервера.
- Старый `profile.json` с открытыми токенами переносится в новое хранилище и удаляется.

### Безопасность
- Убран CORS `*` с credentials. Доступ к API защищён случайным токеном (`X-Nexora-Token`), backend слушает только `127.0.0.1`.
- Защита от path traversal в именах инстансов, файлов и миров. Защита от zip-slip при распаковке архивов.
- Токены шифруются Fernet. Ключ хранится в профиле пользователя и на Windows защищён DPAPI.
- Конфиги записываются атомарно; добавлена миграция схемы конфигурации.

### Интерфейс
- Новый интерфейс: тёмная и светлая темы, переводы ru/en для всех строк, иконка приложения.
- Запросы к API идут в пуле потоков вместо `asyncio.run()` в каждом QThread, поэтому окно не зависает.
- Прогресс фоновых задач отображается в статус-баре.
- Новые экраны: главная с быстрым запуском, диалог инстанса (настройки, моды, ресурспаки, шейдеры, миры, логи), аккаунты, обновлённые серверы и настройки.
- Встроенный backend запускается на свободном порту в том же процессе, поэтому конфликта с портом 8000 больше нет.

### Инфраструктура
- 85 тестов (pytest), покрытие backend и shared — около 80%. Есть smoke-тест GUI.
- Линтер ruff, CI на GitHub Actions (Windows и Linux), сборка PyInstaller, флаг `--self-test` для проверки сборки.
- Добавлен `.gitignore`, из репозитория убраны `__pycache__` и логи.

### API (несовместимые изменения относительно 0.x)
- `/mods/*` заменены на `/content/search`, `/content/projects/{id}` и `/instances/{name}/content/{mod|resourcepack|shader}`.
- Запуск: `POST /instances/{name}/launch` возвращает фоновую задачу вместо `POST /minecraft/launch`.
- Процессы: `/minecraft/processes/*`. Аккаунты: `/auth/accounts/*`.
- WebSocket AI-чата заменён на потоковый `POST /ai/chat` (NDJSON).
- Переменные окружения: префикс `NEXORA_BACKEND_` вместо `QUANTUMLAUNCHER_BACKEND_`.

# Промт для создания сайта Nexora

Скопируйте текст ниже целиком в инструмент для создания сайтов (Claude, v0, Lovable, Bolt и т. п.).
Скриншоты лаунчера положите в папку `screenshots/` рядом с сайтом (имена — в разделе «Материалы»).

---

```text
Сделай одностраничный сайт-лендинг для Nexora — бесплатного лаунчера Minecraft: Java Edition для Windows
с открытым исходным кодом. Сайт статический (HTML + CSS + немного JS, без фреймворков и сборки),
чтобы его можно было выложить на GitHub Pages как есть. Язык — русский, тексты короткие и человеческие.

=== ГЛАВНОЕ ===
Задача сайта — за 10 секунд объяснить, чем Nexora лучше обычного лаунчера, и дать скачать установщик.
Не делай «типичный сайт от ИИ»: никаких эмодзи вместо иконок, градиентных баннеров «Привет!», подписи
под каждым заголовком, стены одинаковых карточек с обводкой и большим скруглением, сине-зелёной палитры.
Стиль — как у самого лаунчера: спокойная премиальная «игровая библиотека» (в духе Steam/Battle.net)
с лёгкой душой Minecraft. Живой контент вместо абстракций: скриншоты интерфейса, цифры.
Асимметричные блоки, разделение отступами и тоном фона, почти без обводок.

=== ДИЗАЙН-ТОКЕНЫ (те же, что в приложении) ===
Тёмная тема «глубинный сланец» (основная):
  bg #121211, surface-1 #1B1A18, surface-2 #23221F, surface-3 #2D2B27,
  text #EDEAE4, muted #9C978D, line #2F2D29,
  accent (янтарь лампы редстоуна) #F0B23A, accent-pressed #D99A22, on-accent #1A1408,
  success #6FBF73, danger #E0614F, info #7FA7D9.
Светлая тема «песчаник» (по prefers-color-scheme): bg #F3EFE6, surface-1 #FBF8F2, surface-2 #ECE6DA,
  surface-3 #E2DACB, text #1E1C18, muted #6E685D, line #DDD5C6, accent #C98A12, on-accent #FFFFFF.
Акцентный цвет — ТОЛЬКО для главной кнопки «Скачать» и мелких выделений.
Шрифты Google Fonts: Onest (текст), JetBrains Mono (версии, размеры, цифры).
Радиусы: 4–6 px (кнопки, плашки), 10 px — только у скриншотов. Сетка 8 px.
Иконки — линейные Lucide (1,5 px), подключить с cdn, без эмодзи.
Анимации сдержанные: 120–180 мс, ease-out, уважать prefers-reduced-motion.

=== СТРУКТУРА СТРАНИЦЫ ===
1. Шапка: логотип (квадрат из двух вертикальных брусков и янтарной «лестницы» из трёх пикселей
   по диагонали между ними) + «Nexora», ссылки «Возможности», «Скачать», «GitHub». Липкая, без тени.
2. Первый экран: слева заголовок «Лаунчер Minecraft, который чинит игру сам»,
   одна строка пояснения, большая янтарная кнопка «Скачать для Windows» и рядом мелким моноширинным
   шрифтом «версия 1.4.0 · 48 МБ · Windows 10/11». Вторичная ссылка «Исходный код на GitHub».
   Справа — большой скриншот главного экрана (screenshots/library.png) с лёгким наклоном или тенью.
3. Полоса фактов (моноширинные цифры): «5 загрузчиков · 4 ядра сервера · 0 рекламы · открытый код».
4. Возможности — не сеткой одинаковых карточек, а чередующимися блоками «текст + скриншот»:
   • Доктор: читает лог вылета, называет причину простыми словами и чинит в один клик
     (не хватило памяти, не та Java, конфликт модов). Скриншот screenshots/doctor.png.
   • Каталог Modrinth: моды, модпаки, ресурспаки, шейдеры, плагины; ставит в выбранную сборку
     с зависимостями, обновляет моды по хэшу, «Турбо» ускоряет сборку. Скриншот screenshots/catalog.png.
   • Свой сервер без белого IP: Fabric, Paper, Purpur или Vanilla; друзья заходят по адресу,
     который выдаёт лаунчер; бэкапы мира автоматически. Скриншот screenshots/network.png.
   • Сборки на любой вкус: Vanilla, Fabric, Quilt, Forge, NeoForge, OptiFine; перенос из Prism,
     MultiMC и CurseForge; точки восстановления перед обновлениями. Скриншот screenshots/wizard.png.
5. Короткий блок «Ещё»: мелкий список в 2 колонки — умные логи и публикация на mclo.gs,
   автообновление лаунчера, тёмная и светлая тема, Ctrl+K, вход Microsoft и офлайн-аккаунты,
   перетаскивание .jar и .mrpack на окно.
6. Блок «Скачать»: крупная кнопка установщика, под ней вторичная ссылка «ZIP без установки»
   и строка «Права администратора не нужны. Лаунчер обновляется сам.»
   Системные требования одной строкой: Windows 10/11 x64, 4 ГБ ОЗУ, интернет для первой установки игры.
7. Вопросы (аккордеон, 4–5 штук): «Это бесплатно?», «Нужна ли лицензия Minecraft?» (для игры по сети
   на лицензионных серверах — да, вход Microsoft; офлайн-аккаунт — для одиночной игры),
   «Windows ругается на неизвестного издателя — что делать?» (файл не подписан; «Подробнее → Выполнить
   в любом случае»), «Где хранятся мои миры?» (%LOCALAPPDATA%\nexoralauncher), «Как удалить?».
8. Подвал: «Nexora не связан с Mojang Studios и Microsoft.», ссылка на GitHub и лицензию, версия.

=== КНОПКА «СКАЧАТЬ» ===
Ссылки не зашивать на конкретную версию. При загрузке страницы JS запрашивает
https://api.github.com/repos/Atomfren/NexoraLauncher/releases/latest
и берёт из assets файл, имя которого оканчивается на "-setup.exe" (установщик) и на "-windows-amd64.zip" (архив);
номер версии берёт из tag_name, размер — из size (показать в МБ с одним знаком).
Если запрос не удался — кнопка ведёт на https://github.com/Atomfren/NexoraLauncher/releases/latest,
а подпись версии скрыть. Без сторонних библиотек.

=== ТЕХНИЧЕСКИ ===
- Файлы: index.html, style.css, script.js, папка screenshots/, favicon (тот же логотип, SVG inline).
- Адаптивность: от 360 px; на телефоне скриншоты под текстом, отступы по бокам 16 px, без горизонтальной прокрутки.
- Доступность: контраст AA, видимый фокус (обводка 2 px цветом accent), alt у всех картинок,
  семантичные заголовки, кнопки — настоящие <a>/<button>.
- Скорость: картинки с loading="lazy" (кроме первого экрана), width/height заданы, без тяжёлых эффектов.
- SEO: title «Nexora — лаунчер Minecraft», description, Open Graph с картинкой screenshots/library.png.
- Никакой аналитики, cookie-баннеров и сбора данных.

цвета surface-2 с подписью экрана.

В конце выведи все файлы целиком.
```

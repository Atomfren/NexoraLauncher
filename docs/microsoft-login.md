# Вход через Microsoft: как получить Client ID

Чтобы игроки входили в свои аккаунты Minecraft, лаунчеру нужно **своё приложение Azure**.
Регистрируется оно один раз, бесплатно, и его идентификатор вписывается в сборку —
игроку после этого ничего делать не нужно.

Сейчас `MS_CLIENT_ID` в [`shared/version.py`](../shared/version.py) пустой, поэтому вход
Microsoft в сборке выключен: окно аккаунтов честно говорит об этом и предлагает аккаунт Nexora.

---

## Главное, что стоит знать заранее

**Одной регистрации мало.** После создания приложения нужно отдельно получить разрешение
пользоваться Minecraft API — по форме <https://aka.ms/mce-reviewappid>. Пока разрешения нет,
`api.minecraftservices.com` отвечает **403**, и вход останавливается на последнем шаге.
Заявки рассматривают примерно раз в неделю, ответ приходит письмом, и одобрение не гарантировано.

Лаунчер этот случай уже распознаёт и пишет игроку прямым текстом, что приложению не выдан
доступ, со ссылкой на форму, — вместо невнятной ошибки.

**Чужой Client ID брать нельзя.** Microsoft считает входы по приложению: подставив чужой
идентификатор, вы повесите своих игроков на чужую регистрацию. Это замечают и на это жалуются.

---

## Шаг 1. Зарегистрировать приложение

1. Откройте <https://portal.azure.com> → **Microsoft Entra ID** → **App registrations**
   → **New registration**. Нужна обычная учётная запись Microsoft; подписка Azure
   и деньги для этого не требуются.
2. **Name** — `NexoraLauncher` (его увидит игрок на странице входа).
3. **Supported account types** — «Personal Microsoft accounts only».

   Это важно: вход с `XboxLive.signin` работает только через тенант `consumers`.
   С `common` или с тенантом организации будут ошибки. В коде лаунчера уже стоит
   `https://login.microsoftonline.com/consumers`.
4. **Redirect URI** — оставьте пустым. Лаунчер входит по коду устройства, и адрес возврата
   ему не нужен.
5. Нажмите **Register**.

## Шаг 2. Разрешить вход без секрета

1. В приложении откройте **Authentication**.
2. Внизу, в разделе **Advanced settings**, включите
   **Allow public client flows** → **Yes** → **Save**.

   Без этого код устройства работать не будет.
3. **Client secret создавать не нужно.** Лаунчер — программа на компьютере игрока, секрет
   в ней всё равно нельзя спрятать, и Microsoft его для такого входа не требует.

## Шаг 3. Подать заявку на доступ к Minecraft API

Заполните форму <https://aka.ms/mce-reviewappid>. Понадобятся **Application (client) ID**
из обзора приложения, название и описание лаунчера, ссылка на сайт.

Ответ придёт письмом. Пока его нет, дальше можно не ходить: вход будет доходить до Minecraft
и получать 403.

## Шаг 4. Вписать идентификатор в сборку

Скопируйте **Application (client) ID** со страницы **Overview** — это строка вида
`00000000-0000-0000-0000-000000000000` — и вставьте в [`shared/version.py`](../shared/version.py):

```python
MS_CLIENT_ID = "ваш-идентификатор"
```

Это не секрет: client id публичных приложений видны всем и попадают в любую сборку.
Секретом был бы client secret, но его мы не заводим.

## Шаг 5. Проверить, не пересобирая лаунчер

До выпуска удобнее проверить через переменную окружения — она перебивает вписанное в сборку:

```bash
set NEXORA_MS_CLIENT_ID=ваш-идентификатор
python -m frontend.main
```

Порядок поиска такой: **настройка игрока → переменная окружения → вписанное в сборку**.
Настройка игрока остаётся для тех, кто собирает лаунчер сам.

---

## Что увидит игрок

| Состояние | Что происходит |
|---|---|
| `MS_CLIENT_ID` пустой | Вкладка Microsoft объясняет, что вход недоступен, кнопка выключена |
| Идентификатор есть, разрешения нет | Вход доходит до Minecraft и показывает ссылку на форму |
| Всё получено | Код устройства → подтверждение в браузере → аккаунт в списке |

## Если что-то не так

- **403 «Invalid app registration»** — нет разрешения на Minecraft API (шаг 3) либо оно
  ещё не применилось: Microsoft просит подождать до суток.
- **Ошибки про тенант** — в приложении выбран не тот тип учётных записей (шаг 1.3).
- **Код устройства не выдаётся** — не включено «Allow public client flows» (шаг 2).
- **«На этом аккаунте Microsoft нет лицензии Minecraft Java Edition»** — приложение и доступ
  в порядке, игра просто не куплена на этом аккаунте.
- **XErr 2148916238** — детская учётная запись: её нужно добавить в семью на xbox.com.
  На официальном лаунчере этого не видно, а на своём приложении — видно.

## Что уже сделано в коде

- `consumers` как тенант и `XboxLive.signin` как scope — [`backend/core/auth.py`](../backend/core/auth.py);
- вход по коду устройства с отменой и таймаутом;
- понятные сообщения на отказ Microsoft, отсутствие лицензии и ошибки Xbox Live;

  не показывает кнопку, которая не сработает;
- проверки — [`tests/test_microsoft_login.py`](../tests/test_microsoft_login.py).

Остаётся только вписать полученный идентификатор.

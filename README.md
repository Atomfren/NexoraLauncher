# NexoraLauncher

Лаунчер Minecraft: Java Edition с отдельными инстансами, загрузчиками модов и каталогом Modrinth.
Backend на FastAPI, интерфейс на Qt Quick (QML, PySide6).

**Версия 1.5.0 «Всё на своих местах»** · Windows / Linux / macOS · Python 3.11+ · GPL-3.0

## Возможности

### Чем Nexora отличается

- **🌍 Свой сервер без белого IP.** Бесплатный сервер для игры с друзьями создаётся в один клик. Туннель e4mc выдаёт публичный адрес, поэтому не нужны ни белый IP, ни проброс портов, ни регистрация. Друзья подключаются с обычного Minecraft. Ядро на выбор: Fabric (моды), Paper или Purpur (плагины), Vanilla. В лаунчере есть консоль, настройки, моды и плагины с Modrinth, автоматические резервные копии мира с восстановлением в один клик и «сборка для друзей». Есть и режим «Играть с друзьями»: открыть свой одиночный мир в интернет можно прямо из игры.
- **🩺 Доктор Nexora.** Игра вылетела? Доктор разберёт лог и crash-report и назовёт причину: не хватает мода, мод для другой версии, несовместимые моды, нехватка памяти, не та Java, сбой Mixin, дубликаты, битые файлы. Исправление — одной кнопкой: установить недостающий мод с Modrinth, отключить конфликтующий, добавить памяти.
- **🧠 Умные логи.** Вместо простыни текста — сводка сеанса, причина вылета, найденные проблемы с кнопками исправления и пояснения к ошибкам простым языком. Шум скрыт, стек-трейсы свёрнуты, мод-виновник подсвечен. Лог можно опубликовать на mclo.gs без личных данных.
- **🔆 OptiFine в один клик.** Лаунчер показывает версии с официального сайта, сам подхватывает скачанный файл и ставит его на Vanilla или Forge. Для Fabric предлагает Sodium + Iris.
- **🕓 Машина времени.** Перед каждым рискованным действием лаунчер делает снимок модов и конфигов. Если сборка сломалась, откат — в один клик.
- **⬆ Умные обновления.** Моды распознаются по хэшу, даже скачанные вручную. Все обновления под вашу версию игры ставятся разом.
- **🚀 Турбо.** Одна кнопка ставит проверенные моды-оптимизации под ваш загрузчик и настраивает память и сборщик мусора Java.
- **📤 Поделиться.** Экспорт сборки в `.mrpack`: файл весит килобайты и открывается в Modrinth App и Prism Launcher.
- **📥 Переезд за минуту.** Лаунчер сам находит сборки Prism Launcher, MultiMC и CurseForge и переносит их со всеми модами, конфигами и мирами.
- **⬆ Автообновление.** Новые версии с сайта ставятся одной кнопкой. Манифест выпуска подписан ключом Ed25519, архив сверяется по SHA-256 — подменённое обновление лаунчер не поставит.

### Основное

- **Инстансы.** У каждой сборки свои моды, миры, настройки и логи. Можно создавать, переименовывать, дублировать, экспортировать и импортировать (`.zip`, `.mrpack`, сборки Prism / MultiMC / CurseForge), а также проверять и восстанавливать файлы игры.
- **Любая версия игры и загрузчики.** Vanilla, Fabric, Quilt, Forge, NeoForge. Версии, библиотеки и ассеты общие для всех инстансов и не скачиваются повторно.
- **Java ставится сама.** Лаунчер скачивает нужную Java от Mojang для каждой версии игры. Можно указать свою Java или найти установленную.
- **Каталог Modrinth.** Моды, модпаки, ресурспаки и шейдеры. При выборе инстанса показываются только совместимые проекты. Обязательные зависимости ставятся автоматически, хэши файлов проверяются, а при обновлении мода старый файл удаляется.
- **Управление контентом.** Моды и паки можно включать и выключать, удалять, добавлять из локального файла. Для миров есть резервная копия в `.zip`, импорт и удаление.
- **Аккаунты.** Вход через Microsoft (код устройства → Xbox Live → Minecraft) и офлайн-аккаунты. Можно держать несколько аккаунтов и переключаться между ними. Токены хранятся в зашифрованном виде.
- **Серверы.** Список избранных серверов со статусом онлайн, MOTD и иконкой. Подключение в один клик.
- **Запуск и логи.** Прогресс установки отображается в статус-баре. Лог игры виден в реальном времени. Если игра упала, лаунчер сообщит об этом. Ведётся статистика времени в игре.
- **Интерфейс.** Тёмная и светлая темы, русский и английский языки.
- **AI-помощник (опционально).** Локальная LLM через `llama-cpp-python`.

## Установка

Скачайте `NexoraLauncher-<версия>-setup.exe` со страницы [релизов](https://github.com/Atomfren/NexoraLauncher/releases/latest) и запустите.
Права администратора не нужны: лаунчер ставится в `%LOCALAPPDATA%\Programs\NexoraLauncher` и дальше обновляется сам.
Без установки — архив `NexoraLauncher-<версия>-windows-amd64.zip`: распакуйте и запустите `NexoraLauncher.exe`.

## Быстрый старт (из исходников)

```bash
python -m venv .venv
.venv\Scripts\activate          # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Подробности — в [QUICKSTART.md](QUICKSTART.md).

### Вход через Microsoft

Microsoft требует, чтобы у лаунчера было собственное приложение Azure с доступом к Minecraft API:

1. Зарегистрируйте приложение на [portal.azure.com](https://portal.azure.com) (*App registrations*). Тип учётных записей — *Personal Microsoft accounts*, в разделе *Authentication* включите *Allow public client flows*.
2. Подайте заявку на доступ к Minecraft API: <https://aka.ms/mce-reviewappid>.
3. Вставьте *Application (client) ID* в **Настройки → Вход через Microsoft**.

Офлайн-аккаунты работают без этого: одиночная игра, LAN и серверы в режиме `online-mode=false`.

## Архитектура

```
┌──────────────────────── NexoraLauncher (один процесс) ───────────────────────┐
│  Frontend (Qt Quick)                                                             │
│   pages/ · dialogs/ · widgets · пул потоков · трекер фоновых задач            │
│        │  HTTP + токен X-Nexora-Token, 127.0.0.1:<случайный порт>             │
│        ▼                                                                      │
│  Backend (FastAPI + uvicorn в фоновом потоке)                                 │
│   api/v1/*  →  core/ (инстансы, установка, запуск, контент, аккаунты, задачи) │
│             →  services/ (Modrinth, локальный AI)                             │
│  Shared: пути, конфиг, шифрование, локализация                                │
└───────────────────────────────────────────────────────────────────────────────┘
```

- Backend можно запустить отдельно и подключить к нему любой клиент — см. [backend/README.md](backend/README.md).
- Долгие операции (установка, загрузка модпака, вход Microsoft) выполняются как **фоновые задачи**. Клиент получает `task_id` и опрашивает `GET /api/v1/tasks/{id}`.
- Где лежат данные:

| Что | Windows | Linux |
|---|---|---|
| Настройки, аккаунты, серверы | `%APPDATA%\nexoralauncher` | `~/.config/nexoralauncher` |
| Инстансы, версии игры, логи | `%LOCALAPPDATA%\nexoralauncher` | `~/.local/share/nexoralauncher` |

  Если задана переменная `NEXORA_HOME`, все данные хранятся в этой папке (портативный режим).

## Разработка

```bash
pip install -r requirements-dev.txt
ruff check .                    # линтер
pytest --cov                    # тесты (backend, shared, smoke-тест GUI)
python scripts/build.py         # сборка dist/NexoraLauncher + zip
powershell -ExecutionPolicy Bypass -File installer/rust/build.ps1 -Version 1.5.0   # установщик setup.exe (нужен Rust)
```

Структура проекта:

```
backend/        FastAPI: api/v1 (эндпоинты), core (бизнес-логика), services (Modrinth, AI)
frontend/       quick/ — интерфейс на QML (основной); app.py, pages/, dialogs/ — прежний (--ui classic)
shared/         paths, config, crypto, i18n, fsutil, version
tests/          pytest: API, установка/запуск (с заглушками), контент, i18n, GUI smoke
scripts/        build.py (PyInstaller), sign_release.py (манифест обновления),
                language_pack.py (языки для сайта), make_icon.py
installer/      rust/ — собственный установщик и деинсталлятор (Rust, egui); nexora.iss — прежний на Inno Setup
resources/      иконки
```

### Выпуск новой версии

Лаунчер обновляется из своего канала: рядом со сборкой лежит `latest.json` (версия, имена файлов,
размеры, SHA-256) и его подпись `latest.json.sig`. Открытый ключ Ed25519 вшит в программу
(`shared/version.py`, `UPDATE_PUBLIC_KEY`), закрытый хранится только у выпускающего и в секрете CI
`NEXORA_RELEASE_KEY`. Лаунчер берёт манифест с `https://nexoralauncher.ru/downloads/latest.json`,
а если сайт недоступен — из последнего релиза GitHub; подпись проверяется в обоих случаях,
и уже из подписанного манифеста берётся SHA-256 архива.

```bash
python scripts/sign_release.py keygen --out release_key.pem   # один раз: пара ключей
python scripts/sign_release.py sign dist --version 1.5.1 --key release_key.pem --notes CHANGELOG.md
python scripts/sign_release.py verify dist/latest.json        # проверить тем же кодом, что и лаунчер
```

Файлы `latest.json` и `latest.json.sig` выкладываются рядом с архивом: на сайт
(`nexora-site/tools/publish_release.py` переносит их без изменений) и в релиз GitHub (это делает CI).

### Языки, которые докачиваются с сайта

В сборку встроены русский и английский. Остальные переводы лежат на сайте в `languages/` и ставятся
из Настроек → «Языки». Список `languages.json` подписан тем же ключом, а SHA-256 каждого пакета берётся
из подписанного списка, поэтому подменить перевод по дороге нельзя.

```bash
python scripts/language_pack.py template --code uk --name "Українська" --out uk.json   # шаблон переводчику
python scripts/language_pack.py build uk.json --out ../nexora-site/languages/          # проверить и собрать
python scripts/language_pack.py index ../nexora-site/languages/ --key release_key.pem  # подписать список
```

`build` не пропустит пакет с лишними ключами или с испорченными подстановками вида `{name}`;
непереведённые строки можно оставить пустыми — лаунчер покажет их по-английски.

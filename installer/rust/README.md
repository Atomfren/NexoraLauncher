# NexoraInstaller

Собственный установщик NexoraLauncher на Rust (egui) вместо Inno Setup.

## Как устроен

Один exe — два режима:

```
[nexora-setup.exe (заглушка + иконка + манифест)][tar.xz с dist\NexoraLauncher][хвост 72 байта]
```

* **С пакетом в конце** — установщик. Окно в стиле лаунчера: выбор папки, ярлык на рабочем столе,
  запуск после установки. Если найдена старая версия, она обновляется на месте.
* **Без пакета** (`uninstall.exe` в папке программы = первые `stub_len` байт установщика) — деинсталлятор.
  Запускается из временной копии в `%TEMP%`, умеет по желанию удалять данные
  (`%LOCALAPPDATA%\nexoralauncher`, `%APPDATA%\nexoralauncher`).

Что делает установка:

1. Закрывает запущенный лаунчер (сначала спрашивает).
2. Если стоит версия от Inno Setup, удаляет её штатным деинсталлятором в тихом режиме (данные пользователя остаются).
3. Распаковывает файлы в `<папка>.~nxnew`, потом целиком подменяет папку программы
   (лишние файлы от прошлых обновлений не остаются, а при ошибке старая версия возвращается).
4. Кладёт `uninstall.exe`, ярлыки в «Пуск» (и на рабочий стол), запись в «Параметры → Приложения»
   (`HKCU\...\Uninstall\NexoraLauncher`). Права администратора не нужны.

Папка по умолчанию та же, что у Inno: `%LOCALAPPDATA%\Programs\NexoraLauncher`. Самообновление лаунчера
(zip с GitHub Releases) продолжает работать как раньше.

## Сборка

Нужны Rust (тулчейн `stable-x86_64-pc-windows-gnu`) и MinGW-w64 (WinLibs) — `dlltool` из тулчейна не работает без ассемблера `as`.

```bash
powershell -ExecutionPolicy Bypass -File build.ps1 -Version 1.5.0
```

Скрипт собирает `nexora-setup.exe` и `nexora-pack.exe`, затем упаковывает `..\NexoraLauncher-<версия>\dist\NexoraLauncher`
в `dist\NexoraLauncher-<версия>-setup.exe`. Сначала нужно собрать сам лаунчер (`python scripts/build.py` в папке версии).

## Параметры командной строки

| Параметр | Что делает |
|---|---|
| `--silent` (`/S`, `/VERYSILENT`) | без окна |
| `--dir <папка>` | куда ставить (тихий режим) |
| `--no-desktop` | без ярлыка на рабочем столе |
| `--launch` | запустить лаунчер после тихой установки |
| `--uninstall` | режим удаления даже у установщика с пакетом |
| `--remove-data` | при удалении стереть и сборки/миры/настройки |

## Файлы

* `src/payload.rs` — формат пакета (хвост, чтение окна файла, распаковка xz).
* `src/bin/pack.rs` — упаковщик: иконка и манифест через `editpe`, tar → xz (LZMA2, блоки по 64 МБ, многопоточно).
* `src/ops.rs` — установка и удаление (фоновый поток, прогресс).
* `src/sys.rs` — Windows: реестр, ярлыки, процессы, проверки пути.
* `src/app.rs` — окно (egui), `src/art.rs` — пиксельная кирка.
* `assets/icon/` — иконка (её генерирует `NexoraLauncher-1.5.0/scripts/make_icon.py`); `old-cube/` — прежняя иконка.
